# Ai-chatbot
This was a project made for a youtube video you can find at: https://youtu.be/9Hqv09cffzA?si=LhbStbcm3IRxOhgE

The model does NOT come pre-trained yet, you will have to train it using your own training data, although in the future I might upload an example checkpoint.cp.

To run this code you will obviously need python an pytorch.

You can technically run the code on cpu but it would be extremely slow, I recommend running it on gpu (that's the device = "cuda" line in train.py), to do that you need to have installed a version of pythorch that includes cuda.

This model is inspired by gpt2.
